# 개통 포털 스타일(밝은 한패스 레드 테마)로 UIX 전환

개통 포털(hanpassusim) 화면처럼 밝고 깨끗한 느낌으로 전체 화면의 겉모습을 바꿉니다. 기능·메뉴 구성·데이터는 그대로 두고 색과 화면 골격만 변경합니다.

## 바뀌는 모습

- **전체 배경**: 밝은 회백색(연한 회색 위에 흰 카드) — 포털처럼 밝고 선명한 화면
- **포인트 색**: 한패스 레드(#D61C29) — 주요 버튼(등록/저장), 선택된 메뉴, 강조 숫자에 사용
- **상단 바**: 진한 남색(네이비) 바에 로고·전화번호·언어/알림/프로필 — 포털과 같은 구성
- **왼쪽 메뉴**: 흰색 배경에 선택된 항목만 연한 빨간 배경 + 빨간 글씨로 표시
- **상태 숫자 카드**: 포털의 상태 타일처럼 파스텔 배경(파랑/초록/빨강/노랑)에 큰 숫자
- **표(테이블)**: 흰 배경, 얇은 구분선, 상태 배지는 포털처럼 파스텔 알약 모양
- **버튼**: 주요 동작은 빨간 버튼, 보조 동작은 흰색 테두리 버튼

## 작업 범위

1. `src/styles.css` — 색 토큰 전면 교체(배경/카드/레드 포인트/네이비 사이드바·상단바), 다크 모드 값도 레드 톤으로 맞춤
2. `src/components/AppSidebar.tsx` — 흰 배경 + 레드 활성 상태 스타일로 조정
3. `src/routes/__root.tsx` — 상단 바를 진한 남색 바로 재구성(로고, 언어 전환, 알림, 프로필)
4. `src/components/StatCard.tsx`, `PageHeader.tsx`, `EmptyState.tsx` — 포털식 파스텔 타일/헤더 스타일 적용
5. 상태 배지·버튼 등 shadcn 변형 점검(레드 primary 적용 확인)
6. 검증: `bunx tsgo --noEmit` + 미리보기 캡처로 주요 화면(고객 관리, 대시보드, 로그인) 확인

## 바꾸지 않는 것

- 메뉴 구성, 권한(한패스 직원/관리자), 동기화·SLA·텔레그램 등 모든 기능 로직
- 폰트는 현재 Sora/Manrope + Pretendard 조합 유지(포털과 유사한 산세리프)
