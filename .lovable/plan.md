# 직원 관리 화면 전문화

지금 직원 관리는 전체 목록을 한 번에 쭉 내려보는 구조라, 검색도 부서별 보기도 안 됩니다. 실제 운영에 필요한 도구를 갖춘 화면으로 바꿉니다.

## 1. 검색

- 상단에 검색창 추가: 이름, 이메일, 전화번호, 부서로 즉시 검색
- 입력하는 즉시 목록이 좁혀지고, 결과 건수를 함께 표시

## 2. 필터

한 줄 필터 바를 추가합니다. 여러 개를 동시에 적용할 수 있습니다.

- 부서 (현재 등록된 부서 목록에서 선택 + "부서 없음")
- 소속 (한패스 / 한패스 모바일)
- 권한 (관리자 / 직원)
- 상태 (승인 대기 / 활성 / 비활성)
- 담당 국가

선택한 필터는 칩으로 표시되고 "필터 초기화" 한 번으로 모두 해제됩니다.
현재 부서가 비어 있는 직원이 52명이라, "부서 없음" 필터로 정리 대상을 바로 찾을 수 있게 합니다.

## 3. 부서 정리 도구

- 부서 입력이 지금은 자유 입력이라 표기가 제각각입니다. 신규 등록·수정 시 기존 부서 목록에서 고르거나 새로 입력할 수 있는 형태로 바꿉니다.
- 목록에서 여러 직원을 체크해 부서를 한 번에 지정하는 기능 추가
- 같은 방식으로 소속 일괄 변경도 지원

## 4. 목록 사용성

- 열 머리글 클릭으로 정렬 (이름, 부서, 소속, 권한, 마지막 접속, 목표)
- 상단 요약: 전체 인원 / 승인 대기 / 활성 / 비활성 건수 (클릭하면 해당 상태로 필터)
- 승인 대기 직원은 지금처럼 맨 위에 강조 유지
- "엑셀 내려받기" 버튼: 현재 필터가 적용된 목록 그대로 CSV 저장
- 모바일에서도 검색·필터가 동일하게 동작 (필터는 접이식)

## 5. 유지되는 것

권한·소속·담당 국가·목표 변경, 승인, 비밀번호 초기화, 비활성화/영구 삭제, 순서 변경, 목표 일괄 설정은 지금 그대로 동작합니다. 순서 변경 화살표는 정렬·필터가 걸려 있지 않은 기본 상태에서만 활성화됩니다(잘못된 순서 저장 방지).

## 기술 메모

- `src/routes/staff.tsx` 내에서 처리. 서버 쿼리는 그대로 두고 `useMemo` 기반 클라이언트 필터/정렬 (현재 80명 규모라 성능 문제 없음).
- 필터 상태는 `useState`로 관리, 부서 목록은 `rows`에서 distinct 추출.
- 일괄 변경은 기존 `admin_set_profile_company` RPC를 반복 호출, 부서는 `profiles.department` 업데이트용 `admin_set_profile_department(_user_id, _department)` SECURITY DEFINER 함수 신규 추가 (관리자 검사 포함, `authenticated`에만 EXECUTE).
- CSV는 클라이언트에서 Blob 생성, UTF-8 BOM 포함.
- i18n `settings.*` 키를 ko/en 양쪽에 추가.
- `bunx tsgo --noEmit` 통과 확인.
