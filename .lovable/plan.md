# 글자를 더 진하고 또렷하게

캡처를 보면 글자가 얇고 작아서 흐리게 보입니다. 기능은 그대로 두고 글자 모양만 바꿉니다.

## 바꾸는 점
1. **글자 굵기 올리기** — 기본 글자를 보통(400)에서 약간 굵게(500)로, 표의 이름·전화번호·숫자는 600으로 바꿉니다.
2. **글자 크기 한 단계 키우기** — 기본 글자 14px → 15px, 표 내용 15px, 표 제목·작은 안내 글자 13px.
3. **흐린 글씨 없애기** — "시작/종료", "고객 국적 · 전체 국가", 검색창 안내 글씨, 사이드바 메뉴 글씨를 더 진하게 바꿉니다.
4. **선택된 탭 숫자** — 빨간 "기존 고객" 탭 안의 숫자(6,531)가 거의 안 보입니다. 흰색으로 또렷하게 바꿉니다.
5. **집계 박스 숫자** — 6,531, 12 같은 숫자를 더 크고 굵게 보이게 합니다.
6. **글자 선명하게 그리기** — 화면 글자를 더 선명하게 그리도록 설정을 바꿉니다.

## 참고
캡처를 보면 브라우저 화면이 90%로 줄여져 있습니다. Ctrl + 0을 누르면 100%로 돌아가 글자가 훨씬 또렷해집니다.

## 기술 상세
- `src/styles.css`: body `font-size:15px; font-weight:500`, `td` 15px, `th` 13px/600 foreground 색, `-webkit-font-smoothing:auto`(얇게 보이는 antialiased 제거), placeholder 색 muted-foreground로 진하게, `--muted-foreground` #374151로 한 단계 더.
- `text-xs`(12px) 전역을 13px로 재정의(`@theme --text-xs: 0.8125rem`), `text-sm` 15px.
- 고객 관리 탭 활성 카운트 클래스 수정(`data-[state=active]` 시 primary-foreground), 집계 박스 숫자 `text-lg font-bold`.
- 사이드바 메뉴 글자 600/foreground.
