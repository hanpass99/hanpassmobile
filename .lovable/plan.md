# AI 학습(FAQ) 181건 일괄 검토

## 현재 상태 (확인됨)
- 화면의 "총 181개"는 **검토 대기 건이 아니라 이미 등록된 답변**입니다 (활성 180, 꺼짐 1). 자동 등록 145, 직접 등록 36.
- 검토 대기(pending) 후보는 **0건**. 따라서 "승인/거절"은 **각 답변을 유지(승인)하거나 끄기(거절)** 하는 뜻으로 처리합니다.

## 판단 기준 (채팅 내역 기반)
유지(승인):
- 운영 규칙과 맞는 답변: 상담 시간·자동응답 안내, 개통/유심 절차, 필요한 서류(외국인등록증 등), 상담원 연결 안내.
- 우즈벡어·러시아어 답변이 모두 있고 내용이 서로 일치.

끄기(거절):
- 같은 질문의 중복(더 오래되고 정확한 1건만 남김).
- 가격·요금제·혜택을 **추측하거나 확정 약속**하는 답변(요금·상품 정보는 신청 페이지가 기준).
- 개인 사례에 한정된 답(특정 고객 번호·이름·날짜), 인사/감사만 있는 답, 의미 없는 짧은 답.
- 우즈벡어/러시아어 답이 서로 다르거나 한쪽이 비었거나 다른 언어로 쓰인 경우.
- 운영 규칙과 모순(예: 상담 시간 외 즉시 처리 약속, 할부·보증 무조건 가능 등).

## 처리 방식
- 181건 전체 질문·답변을 읽고 위 기준으로 분류 → 결과표(유지/끄기 + 한 줄 사유) 작성.
- 거절 건은 **삭제하지 않고 "꺼짐"으로만 변경** → 나중에 화면에서 다시 켤 수 있음.
- 결과 요약(유지 N건 / 끄기 N건, 주요 사유별 건수)을 보고.

## 기술 메모
- `ai_faq_entries.is_active = false` UPDATE만 수행(삭제·스키마 변경 없음). 꺼진 항목은 기존 로직상 자동응답 매칭에서 제외됨.
- 판단 결과표는 /mnt/documents/faq-review.csv 로 저장해 확인 가능하게 함.
