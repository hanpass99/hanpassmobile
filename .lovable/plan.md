# 1년 개통자 업로드 양식 변경

새 양식: **고객명 · 국적 · 개통번호 · 개통일** (4칸)

## 바뀌는 것
1. **샘플 양식 받기** (1년 개통자 탭): 위 4칸만 이 순서로 나옵니다. 판매점·구분·생년월일·요금제·월요금 칸은 빠집니다.
2. **엑셀 올리기**: 4칸 양식을 그대로 읽어 저장합니다. 개통번호는 전화번호로, 개통일은 개통일로 저장합니다. 같은 번호의 고객이 이미 있으면 지금처럼 1년 개통자로 옮기고 내용을 갱신합니다.
3. 빠진 칸이 없어도 오류 없이 올라갑니다. 예전 양식 파일을 올려도 계속 읽힙니다.
4. 다른 탭 양식은 그대로 둡니다. 저장된 고객 기록은 바뀌지 않습니다.

## 기술 상세
- `customers.lazy.tsx` `downloadSample`의 one_year_activation header/sample을 4칸으로 교체.
- `onUpload` one_year 분기: 판매점/구분/생년월일/요금제/월요금은 선택 항목으로 유지(있으면 저장), 필수는 고객명·개통번호·개통일 확인.
- DB 변경 없음.
