# 대출자 관리에서 OB 콜 진행하기

## 지금 상태
대출자 관리 탭은 이름·전화·국적·대출시작일만 보이는 읽기 전용 명단입니다. 상태, 담당자, 통화, 메모 기능이 없습니다.

## 바꾸는 점
대출자 2,819명을 다른 고객 탭(기존 고객, 한패스앱 신청자 등)과 **같은 방식의 OB 콜 목록**으로 바꿉니다.
- **상태**: 미처리·진행중·부재·개통 완료 등 다른 탭과 같은 상태와 집계 박스
- **담당자**: 담당자 지정·변경, 담당자별 현황. 새로 넣을 때 다른 탭과 같은 규칙(국가별)으로 자동 배정
- **전화 걸기**, 통화 차수(1차·2차·3차), 메모, 상태 변경 기록
- **필터**: 국가, 대출시작일 기간(오늘·이번 주·이번 달), 검색, 엑셀 내려받기·올리기
- 표 칸: 고객명 · 전화번호 · 국적 · 대출시작일 · 담당자 · 상태

## 데이터 옮기기
- 고객 목록에 **"대출자"** 종류를 새로 만들고, 대출자 2,819명을 그 종류로 복사합니다. 대출시작일은 등록일 칸에 넣습니다.
- 국적은 국가 목록과 맞춥니다(UZ·RU·KZ·KG·TJ는 CIS로).
- 원래 대출자 명단은 지우지 않고 그대로 둡니다(백업).

## 확인
대출자 탭에서 상태·담당자 변경, 메모 작성, 전화 걸기 버튼이 다른 탭처럼 동작하는지 화면에서 확인합니다.

## 기술 상세
- 마이그레이션: `ALTER TYPE customer_pool ADD VALUE 'loan_borrower'`.
- 데이터 복사(INSERT ... SELECT from loan_borrowers → customers, pool='loan_borrower', signup_date=loan_start_date, country_id via countryLookupCode 규칙, status='new'). 기존 트리거(auto_assign_customer, 채널 설정)가 그대로 적용됨.
- `customers.lazy.tsx`: POOLS에 loan_borrower 추가(라벨 "대출자 관리"), 기존 `loan_borrowers` 탭/`LoanBorrowerList` 대신 공통 표 사용, 대출시작일 열 표시. 한패스 직원 숨김 유지.
- `customer_pool_counts`, 업로드 양식(고객명·전화번호·국적·대출시작일) 연결.
