# 개통 포털과 동일한 글자 디자인 및 메뉴 색상 조정

업로드한 개통 포털 화면을 기준으로 모든 메뉴와 업무 화면의 글꼴, 크기, 굵기, 간격을 통일하고 사이드바의 빨간색 사용을 줄입니다. 기능과 데이터는 변경하지 않습니다.

## 변경 사항

- **전체 글꼴**: 현재의 장식적인 영문 제목 글꼴을 제거하고, 참고 화면처럼 한글과 영문이 자연스럽게 섞이는 깔끔한 고딕체 계열로 통일합니다.
- **제목 체계**: 화면 제목, 카드 제목, 설명, 표 머리글, 숫자, 버튼의 크기와 굵기를 참고 화면의 조밀하고 단정한 비율로 맞춥니다.
- **글자 간격**: 과한 대문자·넓은 자간·강한 굵기를 줄이고, 참고 화면처럼 일반적인 자간과 중간 굵기를 사용합니다.
- **왼쪽 메뉴**: 기본 메뉴는 중성 회색 글자와 아이콘으로 표시합니다. 빨간색은 현재 선택된 메뉴의 아이콘·글자와 아주 연한 선택 배경에만 사용합니다.
- **메뉴 그룹 제목**: 진한 강조 대신 작고 차분한 회색으로 정리해 메뉴 전체가 빨갛게 보이지 않도록 합니다.
- **상단 및 본문**: 진한 남색 상단바, 밝은 배경, 흰 카드, 파스텔 상태 색상은 유지하면서 글자 표현만 참고 화면에 맞춥니다.

## 적용 범위

- 로그인·회원가입 화면
- 대시보드 및 모든 고객/상담/관리 화면
- 왼쪽 메뉴, 상단바, 카드, 표, 입력창, 버튼, 상태 표시

## 확인

- 데스크톱과 모바일에서 글자가 잘리지 않는지 확인
- 대시보드와 고객 관리 화면을 참고 이미지와 나란히 비교
- 선택 메뉴 외에는 빨간 글자나 빨간 아이콘이 남지 않았는지 점검
- 기능 및 타입 검사 통과 확인
