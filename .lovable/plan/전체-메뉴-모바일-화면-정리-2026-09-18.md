# 전체 메뉴 모바일 화면 정리

휴대폰에서 글자와 탭이 겹치고 표가 화면 밖으로 잘리는 문제를 모든 메뉴에서 점검하고, 기능과 데이터는 그대로 유지하면서 모바일 전용 배치를 적용합니다.

## 변경 사항

- **공통 화면 틀**: 상단 제목·설명·버튼을 작은 화면에서 세로로 자연스럽게 배치하고, 본문 여백과 카드 안쪽 간격을 줄입니다.
- **고객 관리**: 메뉴 탭을 가로 스크롤 가능한 한 줄 목록으로 바꾸고 선택된 탭이 분명히 보이게 합니다. 작업 버튼은 모바일에서 줄바꿈하며, 상태 카드는 읽기 쉬운 2열을 유지합니다.
- **긴 목록과 표**: 고객·직원·통화 기록·SLA 등 넓은 표는 모바일에서 핵심 정보 중심의 카드형 목록으로 표시하거나 안전한 가로 스크롤을 제공합니다. 데스크톱 표는 그대로 유지합니다.
- **직원 관리**: 직원 이름, 이메일, 소속, 권한, 국가, 상태와 주요 작업을 모바일 카드로 정리해 현재처럼 열이 잘리거나 행 높이가 과도해지지 않게 합니다.
- **메시지 화면**: 문자·텔레그램·공지·브로드캐스트·AI 화면의 목록과 대화 영역이 작은 화면에서 겹치지 않도록 한 화면씩 전환되는 배치를 적용합니다.
- **대시보드와 통계**: 날짜 필터, 그래프, 순위, 숫자 카드가 화면 폭 안에 맞도록 조정하고 긴 이름과 수치는 줄바꿈 또는 말줄임 처리합니다.
- **팝업과 입력창**: 회원가입, 설정, 직원 추가, 상세 보기 등 모든 팝업의 최대 높이와 스크롤을 휴대폰 화면에 맞춥니다.
- **떠 있는 AI 버튼**: 상단 메뉴와 주요 버튼을 가리지 않도록 모바일 기본 위치와 열린 채팅창 크기를 조정합니다.

## 확인

- 사이드바에 표시되는 모든 메뉴를 440px 휴대폰 화면에서 순서대로 확인
- 고객 관리의 모든 탭과 직원 관리의 실제 데이터 화면 확인
- 화면 전체의 의도치 않은 가로 밀림, 겹침, 잘림 검사
- 데스크톱 화면이 기존과 동일하게 유지되는지 함께 확인
- 기능 및 타입 검사 통과 확인
