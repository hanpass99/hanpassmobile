# 기존 고객 업로드 양식 변경

새 양식 순서: **고객명 · 선후불 · 전화번호 · 개통일 · 요금제 · 국적 · 신분증번호**

## 바뀌는 것
1. **샘플 양식 다운로드** (기존 고객 탭): 위 7개 칸, 이 순서로 나옵니다. (기존 "메모" 칸은 빠집니다)
2. **엑셀 업로드**: 새 양식의 칸을 모두 읽어서 저장합니다.
   - 선후불 → 고객의 "구분" 값으로 저장 (예: 선불 / 후불)
   - 신분증번호 → 새로 만드는 "신분증번호" 칸에 저장
   - 국적 → 지금처럼 국가 코드/이름으로 담당 국가 매칭
3. **기존 고객 탭 목록**: "선후불", "신분증번호" 칸을 표에 추가해서 올린 내용을 볼 수 있게 합니다. 엑셀 내려받기에도 포함됩니다.

다른 탭(한패스앱 신청자, 페이스북, 친구 추천 등)의 양식은 그대로 둡니다.

## 기술 상세
- DB: `customers`에 `id_number text NULL` 칼럼 추가 (추가형 변경, 기존 데이터 영향 없음). 선후불은 기존 `customer_type` 칼럼 사용.
- `customers.lazy.tsx`: `downloadSample` existing 헤더/샘플 교체, `onUpload` 헤더 매핑에 `선후불`(customerType 별칭), `신분증번호/외국인등록번호/id_number` 추가, `ImportCustomer`·`CustomerRow` 타입에 `id_number` 추가, existing 탭 표·엑셀 내보내기에 두 칸 추가.
- `search_customers` RPC가 행 전체(`to_jsonb`)를 반환하는지 확인 후, 아니면 반환 필드에 `id_number` 추가.
